# Experiencia 4: C

Esta experiencia está diseñada para practicar la programación en C. A continuación se describen los ejercicios que se deben realizar:

## Ejercicios

### Ejercicio 1
Implementa un programa en C que realice las siguientes operaciones básicas:
- Suma
- Resta
- Multiplicación
- División

### Ejercicio 2
Escribe un programa en C que lea una cadena de caracteres y determine si es un palíndromo.

### Ejercicio 3
Desarrolla un programa en C que utilice estructuras para almacenar y manipular información de estudiantes (nombre, edad, calificación).

### Ejercicio 4
Implementa las siguientes funciones recursivas en C:
- **Ejercicio 5.1:** Una función recursiva para calcular el factorial de un número.
- **Ejercicio 5.2:** Una función recursiva para resolver el problema de la secuencia de Fibonacci. El programa debe imprimir los primeros n números de Fibonacci, donde n es proporcionado por el usuario.

## Compilación y Ejecución

Para compilar los programas, puedes usar el siguiente comando en la terminal:

```sh
gcc -o nombre_del_programa nombre_del_archivo.c
